# SprintFlow 제품 기획서

## 1. 제품 개요

SprintFlow는 Jira의 익숙한 업무 흐름을 로컬 단일 사용자 환경에 맞게 단순화한 작업 및 일정 관리 도구입니다. 초기 버전은 인증, 권한, 조직 관리 없이 프로젝트 운영자가 한 화면에서 작업 현황을 파악하고 이슈를 관리하는 데 초점을 둡니다.

## 2. 목표

- 프로젝트 작업을 보드, 백로그, 일정, 이슈 상세 흐름으로 관리한다.
- 하위작업과 진행률을 통해 큰 작업의 완료 상태를 빠르게 파악한다.
- 스프린트 단위로 작업 계획과 진행 상황을 관리한다.
- 담당자 목록을 설정에서 직접 관리한다.
- 로컬 DB를 원클릭으로 백업하고 복원할 수 있게 한다.

## 3. 비목표

- 계정 생성, 로그인, 권한 관리
- 외부 Jira 연동
- 실시간 협업
- 클라우드 배포 및 멀티 테넌트 운영
- 실제 파일 업로드 저장소

## 4. 주요 사용자

- 기획자: 요구사항, 이슈, 일정, 우선순위를 관리한다.
- 개발자: 작업 상태, 하위작업, 담당 작업을 확인한다.
- QA: 버그, 검토 상태, 마감 예정 작업을 추적한다.
- 프로젝트 리드: 스프린트 진행률과 전체 병목을 확인한다.

## 5. 핵심 사용자 흐름

### 작업 계획

1. 백로그에서 새 이슈를 만든다.
2. 타입, 우선순위, 담당자를 지정한다.
3. 활성 스프린트 또는 다음 스프린트로 배치한다.
4. 필요한 경우 하위작업을 추가한다.

### 진행 관리

1. 보드에서 상태 컬럼별 이슈를 확인한다.
2. 드래그하거나 상세 패널에서 상태를 변경한다.
3. 하위작업 완료 상태에 따라 진행률을 확인한다.
4. 댓글과 첨부 메타데이터로 맥락을 남긴다.

### 일정 확인

1. 일정 화면에서 마감일 기준 월간 작업을 확인한다.
2. 마감 임박 또는 지연 위험 작업을 상세에서 조정한다.

### 설정 관리

1. 설정 화면에서 담당자를 추가, 수정, 삭제한다.
2. 중요한 변경 전 서버 백업 저장을 실행한다.
3. 필요 시 최신 백업 또는 백업 파일로 복원한다.

## 6. 정보 구조

- 대시보드
- 보드
- 백로그
- 일정
- 이슈
- 설정

## 7. 현재 구현 범위

- 단일 프로젝트 샘플 워크스페이스
- 4개 기본 상태: 할 일, 진행 중, 검토 중, 완료
- 2개 스프린트: 활성 스프린트, 계획 스프린트
- 이슈 타입: 에픽, 스토리, 작업, 버그, 하위작업
- 우선순위: 긴급, 높음, 보통, 낮음
- 담당자 관리
- JSON 백업/복원

## 8. 향후 검토 항목

- 프로젝트 다중 생성 및 전환
- 상태 워크플로우 커스터마이징
- 스프린트 시작/종료 처리
- 첨부파일 실제 업로드 저장
- 검색 고도화와 saved filter
- 보고서: 번다운 차트, 누적 흐름도, 담당자별 처리량
- 계정/권한 도입
